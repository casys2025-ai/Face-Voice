# Face Voice

Aplicativo desktop para Windows mantido pela CA Sys.

## Build pela Central

A Central instala as dependências listadas em `requirements.txt`, executa `build.bat` e pode publicar o executável como release no GitHub.

## Build manual

Com Python 3 instalado, execute `build.bat`. O executável será criado em `dist/`.

## Privacidade

Fotos de pessoas, banco de reconhecimento facial, modelos biométricos e registros de presença são dados locais. Eles são excluídos deste repositório e das releases.
